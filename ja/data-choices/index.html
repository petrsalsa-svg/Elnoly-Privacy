データを管理

ワードローブのデータ、非公開バックアップ、権限、プライバシー請求をいつでも管理できます。

アプリデータとワードローブバックアップを削除

衣類写真、アイテム、コーデ、着用履歴、プラン、任意の体型バランス・パーソナルカラー、スタイリストの記憶、キャッシュ、非公開バックアップを削除するには：

  1. Elnolyを開きます。
  2. プロフィールを開きます。
  3. プライバシーとデータを選びます。
  4. ローカルデータとワードローブバックアップを削除をタップして確認します。

ワードローブバックアップは初期状態でオフです。オフにすると端末内のワードローブは残り、クラウドコピーが削除されます。アプリを削除しただけでは、以前オンにしたElnolyバックアップは再インストール時の復元用に残ります。AppleのバックアップはAppleアカウントと端末の設定で別途管理します。

アカウントを削除

プロフィール → アカウント → アカウントを削除を選び、確認します。仮名化されたサーバーアカウント、セッション、スタイルプロフィール、App Attest記録、購入資格とのアカウント上の紐付け、非公開R2データを削除した後、端末内データを消去します。法令上必要な購入・セキュリティ記録は例外となる場合があります。

家族の管理プロフィールを削除

プロフィール → 使用中のワードローブ → 家族メンバーを管理で対象メンバーを選び、削除します。そのメンバーの端末内衣類、カタログ写真、荷造りプランが削除され、成人のメインワードローブには影響しません。

権限を取り消す

iPhoneの設定 → アプリ → Elnolyで、写真、カメラ、位置情報へのアクセスを変更できます。権限を取り消すと該当機能は使えなくなりますが、その他のローカルワードローブは利用できます。

開示・訂正・削除を請求

もっとも簡単な削除方法はアプリ内のアカウントを削除です。その他の請求はPetr.salsa@icloud.comへ送ってください。可能であればプロフィールの匿名サポートID、日時、タイムゾーン、利用機能を記載し、衣類写真、パスワード、決済情報などの機密情報は送らないでください。

相談・苦情

まずメールでご連絡ください。日本では個人情報保護委員会の案内も利用できます。
